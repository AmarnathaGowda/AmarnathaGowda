## 🚀 Flagship Project: End-to-End AI Text & Voice Agent for HRMS

A production-grade AI assistant integrated into an HRMS platform.

### 🔹 Capabilities
- Text-based AI chatbot for HR queries  
- Voice-based AI agent (speech-to-text + text-to-speech)  
- Employee policy Q&A using RAG  
- Resume screening and candidate scoring  
- Automated interview question generation  
- HR analytics insights for managers  

### 🔹 Architecture
- Backend: Python, FastAPI  
- LLMs: OpenAI / Open-source LLMs  
- RAG: LangChain + Vector DB (FAISS / Pinecone)  
- Speech: Whisper / TTS pipelines  
- Auth & Access Control: Role-based (Employee, HR, Admin)  
- Cloud: AWS (S3, EC2, EKS)  
- Deployment: Docker + Kubernetes  

### 🔹 Business Impact
- Reduced HR manual workload  
- Faster employee support  
- Scalable AI across multiple clients  
- Secure multi-tenant architecture
